WebTransport reliability attributes

Adds two attributes to WebTransport: the per-session reliability instance attribute and the static supportsReliableOnly attribute. Together they tell an application whether the browser can run WebTransport over exclusively reliable (TCP / HTTP/2) connections, and whether an established session can carry unreliable traffic such as datagrams — so a game, media or collaboration client can pick datagrams or reliable streams before it commits to a wire strategy.

what Chrome actually returns

The specification allows three outcomes; Chromium can only produce two of them today, because it has no HTTP/2 fallback:

  • transport.reliability is "pending" from construction, and becomes "supports-unreliable" in the same task that resolves transport.ready. Chromium only establishes sessions over HTTP/3 connections that negotiated H3 Datagram support, so it never reports "reliable-only".
  • A session that fails to establish never leaves "pending": both the spec’s establishment steps and Chromium’s web_transport.cc assign the value only on successful establishment. Read it after await transport.ready, not after closed.
  • WebTransport.supportsReliableOnly is hard-coded to false in Chromium — on a network that blocks UDP, Chrome’s session fails instead of falling back.
  • The related requireUnreliable constructor option is not in Chromium’s WebTransportOptions IDL, so Chrome ignores it as an unknown dictionary member (BCD records Chrome false for it). Chrome behaves as if it were always true.
// Feature-detect: the attributes are new even where WebTransport is not.
if (typeof WebTransport !== "undefined" && "reliability" in WebTransport.prototype) {
  if (!WebTransport.supportsReliableOnly) {
    // Chrome today: no TCP fallback, so keep your WebSocket path for UDP-blocked networks.
  }
  const transport = new WebTransport("https://example.com:4433/wt");
  console.log(transport.reliability); // "pending"
  await transport.ready;
  console.log(transport.reliability); // Chrome: "supports-unreliable"
}
Source: Chromium web_transport.cc (reliability_ set once on establishment; supportsReliableOnly() returns false), web_transport.idl, ChromeStatus summary, read 2026-11-15
