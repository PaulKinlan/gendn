WebTransport reliability attributes

Adds the WebTransport.reliability instance attribute and the static WebTransport.supportsReliableOnly attribute. Together they tell you whether the browser supports WebTransport over exclusively reliable connections, and whether an established session supports unreliable transport such as datagrams. In Chromium, reliability starts as "pending" and becomes "supports-unreliable" once an HTTP/3 WebTransport connection is established. Chromium has no HTTP/2 fallback, so WebTransport.supportsReliableOnly returns false: every established session uses HTTP/3 and supports unreliable datagrams.

// IDL (WebTransport, W3C)
interface WebTransport {  // excerpt: the two members this feature adds
  readonly attribute WebTransportReliabilityMode reliability;
  static readonly attribute boolean supportsReliableOnly;
};

enum WebTransportReliabilityMode {
  "pending",
  "reliable-only",
  "supports-unreliable",
};
