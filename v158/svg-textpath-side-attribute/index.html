SVG textPath side attribute

The SVG 2 side attribute on <textPath> (side="left" default, or side="right") chooses which side of a path text follows; setting side="right" effectively reverses path direction for text layout so authors can place text inside or outside a closed shape such as a circle without duplicating or reversing path data. Chrome 158 also exposes the reflected SVGTextPathElement.side SVGAnimatedEnumeration property and its TEXTPATH_SIDETYPE_* constants.
