Translator API

A built-in on-device API for translating text between languages without network access. Available via self.ai.translator. Supports creation of translator sessions targeting a source and target language pair, with streaming output support.

this feature is documented on MDN

MDN: Translator and Language Detector APIs

MDN covers the full Translator interface including availability(), create(), translate(), translateStreaming(), browser compatibility, and usage examples. gendn doesn't duplicate that here.

Translateconst result = await t.translate(text)
