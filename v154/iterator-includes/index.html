Iterator Includes

Adds Iterator.prototype.includes(searchElement, skippedElements), letting JavaScript code test whether an iterator yields a given value using SameValueZero equality without materializing an intermediate array, short-circuiting and closing the iterator as soon as a match is found.

what Chrome 154 actually does

Verified against the TC39 Iterator Includes specification and ChromeStatus 5205192866922496:

  • SameValueZero matching with early close: Consumes elements lazily via IteratorStepValue and compares each yielded value against searchElement using SameValueZero (so NaN matches NaN, and -0 matches +0). On the first match, it immediately invokes IteratorClose and returns true, allowing finite matches inside infinite generators.
  • Strict skippedElements validation: The optional second argument (skippedElements, defaulting to 0) accepts only undefined, +Infinity, or an integral Number in [0, Number.MAX_SAFE_INTEGER]. Passing a non-number or non-integer throws a TypeError; passing a negative value (including -Infinity) or a finite integer above 2^53 - 1 throws a RangeError. In all validation failure paths, the engine calls IteratorClose on this before throwing.
  • +Infinity skips every element: Passing Infinity as skippedElements consumes a finite iterator to completion and returns false (and never terminates on an infinite iterator).
  • Feature detection & fallback: Check typeof Iterator !== "undefined" && typeof Iterator.prototype.includes === "function"; fall back to a for...of loop with Object.is(x, target) || x === target when supporting older engines or Node.js/Deno releases without it.
function* naturals() {
  let n = 0;
  while (true) yield n++;
}

function iteratorIncludes(iter, target, skip = 0) {
  if (typeof iter.includes === "function") {
    return iter.includes(target, skip);
  }
  let seen = 0;
  for (const value of iter) {
    if (seen++ < skip) continue;
    if (value === target || (Number.isNaN(value) && Number.isNaN(target))) {
      return true;
    }
  }
  return false;
}

const found = iteratorIncludes(naturals(), 42, 10);
console.log({ found });
