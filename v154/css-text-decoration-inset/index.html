CSS text-decoration-inset

A CSS Text Decoration Level 4 property that controls how far underlines, overlines, and line-throughs are inset from — or, with negative values, extended beyond — the edges of the decorated text run. It accepts auto, lengths, and percentages, in one-value (both ends) or two-value (start, end) form, replacing background-gradient and extra-element workarounds for tuned decoration spacing and reveal effects.

Experimental in Chrome — may still be mid-rollout

The milestone=154 listing files this under “Enabled by default”, but as of 2026-09-20 the runtime flag record for CSSTextDecorationInset still reads status: "experimental" at trunk and the ChromeStatus record’s implementation status reads “Proposed” — so the property may not yet be on by default in your Chrome 154. To test regardless: enable chrome://flags/#enable-experimental-web-platform-features or launch with --enable-blink-features=CSSTextDecorationInset, and feature-detect with CSS.supports("text-decoration-inset", "0.1em") before relying on it.
