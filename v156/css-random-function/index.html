CSS random() function

A CSS Values Level 5 math function that resolves to a random numeric value drawn uniformly between a minimum and a maximum, optionally stepped. By default each random() instance resolves to its own distinct value; an optional leading <random-key> argument controls whether and how a resolved value is shared across properties and elements. Shipped enabled-by-default in Chrome 156; already shipping in Safari 26.2.
