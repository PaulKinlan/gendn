CSS random() function

A CSS Values Level 5 function that resolves to a random numeric value within an author-specified range: top: random(0%, 100%) scatters elements, animation-delay: random(0s, 2s) desynchronizes animations. An optional <random-key> first argument (auto, a <dashed-ident> and/or element-scoped cache key, or fixed <number>) controls whether separate uses of random() share one random value or each draw their own, and an optional third <calc-sum> argument quantizes the result to a step.
