Chrome 151 removes support for macOS 12

Chrome 151 is the first release that requires macOS 13 Ventura or later. Chrome 150 is the last version to support macOS 12 Monterey. Users on macOS 12 will continue to run Chrome 150 but will stop receiving updates, including security fixes.

End of support Users running macOS 12 Monterey are stranded on Chrome 150 as of Chrome 151 (stable July 28, 2026). Their browser continues to work but no longer receives security, stability, or feature updates from Chrome 151 onwards.

what this means and system requirements

Apple ended security support for macOS 12 Monterey in 2024. To align with Apple's support window and maintain browser security guarantees, Chrome removed support for macOS 12 in Chrome 151 (stable July 28, 2026). The updated baseline requirement per Chrome browser system requirements requires macOS 13 Ventura or later for all Chrome 151+ desktop installations.

Machines running macOS 12 that already have Chrome installed will retain Chrome 150 and can continue running it, but Chrome will display a warning infobar and will not receive further updates. Security vulnerabilities discovered after Chrome 150's release will not be patched on those machines, creating ongoing exposure for unmanaged installations.

Users who can update their Mac to macOS 13 Ventura or later should do so to continue receiving Chrome updates. For new installations or manual updates on macOS 12, the installer will refuse installation or fail to launch Chrome 151+ binaries due to SDK and OS version minimums. Some older Mac hardware is not eligible for macOS 13 and will remain permanently on Chrome 150.

Source: chromestatus.com/feature/5077742779498496; Chrome browser system requirements

examples

Web applications and administration scripts can inspect client platform version via User-Agent Client Hints (navigator.userAgentData) to detect clients frozen on macOS 12:

// Detect client platform version via User-Agent Client Hints
if (navigator.userAgentData && navigator.userAgentData.platform === "macOS") {
  navigator.userAgentData.getHighEntropyValues(["platformVersion"])
    .then(({ platformVersion }) => {
      // macOS Monterey reports major version 12
      const major = parseInt(platformVersion.split(".")[0], 10);
      if (major <= 12) {
        console.warn("Client running macOS 12 Monterey: Chrome updates end at Chrome 150.");
      } else {
        console.log("Client running macOS 13+ (Chrome 151+ supported).");
      }
    })
    .catch((err) => {
      console.error("Failed to query platformVersion hint:", err);
    });
}
