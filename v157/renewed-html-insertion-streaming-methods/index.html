Renewed HTML insertion&streaming methods

Ships a unified, Sanitizer- and Trusted-Types-aware family of DOM HTML insertion and incremental streaming methods across Element, ShadowRoot, and CharacterData (via NonDocumentTypeChildNode): positional string methods (appendHTML, prependHTML, beforeHTML, afterHTML, replaceWithHTML and their *Unsafe variants), WritableStream-returning streaming methods (streamHTML, streamAppendHTML, streamPrependHTML, streamBeforeHTML, streamAfterHTML, streamReplaceWithHTML and *Unsafe variants), opt-in script execution via SetHTMLUnsafeOptions.runScripts, and Trusted Types TrustedTypePolicy.createParserOptions() producing opaque TrustedHTMLParserOptions.

Limited availability — shipped enabled by default in Chrome 157 and Edge 157; Firefox and Safari have not shipped

  • Edge · 157 (shipped 2026-11-05)

why it exists

Dynamic HTML insertion on the web platform historically split across incompatible APIs: innerHTML and outerHTML replaced whole subtrees without sanitization; insertAdjacentHTML() took error-prone position strings ("beforebegin", "afterbegin", "beforeend", "afterend") and lacked safe sanitization or streaming; Range.createContextualFragment() was the only way to run embedded <script> elements (with quirky pre-insertion image preloading); and streaming server-rendered HTML or AI output into a live element required manual buffering or detached-document workarounds. Furthermore, Trusted Types previously relied on transforming complete HTML strings via createHTML(), which could not govern streaming sinks or sanitizer configurations.

Chrome 157 ships a coherent 22-new-method surface (plus updated setHTMLUnsafe() and Document.parseHTMLUnsafe() overloads) that pairs familiar DOM positional names with explicit safe vs. *Unsafe variants, returns a standard WritableStream for incremental parsing, adds opt-in { runScripts: true } on unsafe options, and introduces TrustedTypePolicy.createParserOptions() so Trusted Types policies can inspect or override parser options without buffering streamed HTML. Earlier trial drafts are archived at /v148/renewed-html-insertion-streaming-methods/ and /v153/renewed-html-insertion-streaming-methods/.

Source: WICG dynamic-markup-revamped explainer; ChromeStatus API record 5054329641893888; blink-dev Intent to Ship.

Container positional methods: appendHTML(), prependHTML(), and *Unsafe variants

Inputs. Exposed on Element and ShadowRoot. Safe methods (appendHTML(html, options?), prependHTML(html, options?)) take a DOMString and optional SetHTMLOptions ({ sanitizer }, defaulting to the safe "default" sanitizer). Unsafe methods (appendHTMLUnsafe(html, options?), prependHTMLUnsafe(html, options?)) take TrustedHTML or DOMString and optional SetHTMLUnsafeOptions ({ sanitizer, runScripts }) or TrustedHTMLParserOptions.

Outputs. Return undefined synchronously. appendHTML() / appendHTMLUnsafe() parse html in the receiver’s context (replacing insertAdjacentHTML("beforeend", ...)) and insert the resulting nodes after the receiver’s last child; prependHTML() / prependHTMLUnsafe() insert before the receiver’s first child (replacing insertAdjacentHTML("afterbegin", ...)). When invoked on an HTMLTemplateElement, Blink targets template.content automatically.

Source: Blink element.idl; shadow_root.idl; container_node.cc.

Sibling positional methods: beforeHTML(), afterHTML(), replaceWithHTML(), and *Unsafe variants

Inputs. Defined on NonDocumentTypeChildNode, so exposed on both Element and CharacterData (Text, Comment, ProcessingInstruction, CDATASection) — but not DocumentType or ShadowRoot. Safe variants (beforeHTML, afterHTML, replaceWithHTML) accept (DOMString html, optional SetHTMLOptions options = {}); unsafe variants (beforeHTMLUnsafe, afterHTMLUnsafe, replaceWithHTMLUnsafe) accept ((TrustedHTML or DOMString) html, optional (SetHTMLUnsafeOptions or TrustedHTMLParserOptions) options = {}).

Outputs. Return undefined synchronously. Parse html using the node’s parent container as the fragment parsing context and insert immediately before the node (beforeHTML*, replacing insertAdjacentHTML("beforebegin", ...)), immediately after the node (afterHTML*, replacing insertAdjacentHTML("afterend", ...)), or in place of the node (replaceWithHTML*, replacing outerHTML = ...). If the node has no parent (detached), these synchronous methods perform Trusted Types checks on *Unsafe and then return silently as a no-op (matching ChildNode.before()/after()/replaceWith()).

Source: Blink non_document_type_child_node.idl; node.cc.

Container streaming methods: streamHTML(), streamAppendHTML(), streamPrependHTML(), and *Unsafe variants

Inputs. Exposed on Element and ShadowRoot. Safe variants (streamHTML, streamAppendHTML, streamPrependHTML) accept optional SetHTMLOptions; unsafe variants (streamHTMLUnsafe, streamAppendHTMLUnsafe, streamPrependHTMLUnsafe) accept optional SetHTMLUnsafeOptions or TrustedHTMLParserOptions. Unlike the synchronous setters, streaming methods take no HTML string argument at creation time; callers write string chunks into the returned stream.

Outputs. Return a new WritableStream backed by an incremental HTML fragment parser targeting the receiver (or template.content for <template>). streamHTML() / streamHTMLUnsafe() remove existing children immediately upon creation and stream replacement children; streamAppendHTML() / streamAppendHTMLUnsafe() stream after existing children; streamPrependHTML() / streamPrependHTMLUnsafe() stream before the initial firstChild snapshot. Each written chunk is coerced to DOMString and parsed incrementally into the live DOM; closing the stream flushes the parser and resolves once parsing (and any deferred/blocking streamed scripts under runScripts: true) finishes.

Source: Blink container_node.cc; Blink html_stream.cc; WHATWG HTML Standard.

Sibling streaming methods: streamBeforeHTML(), streamAfterHTML(), streamReplaceWithHTML(), and *Unsafe variants

Inputs. Defined on NonDocumentTypeChildNode (exposed on Element and CharacterData). Safe variants (streamBeforeHTML, streamAfterHTML, streamReplaceWithHTML) take optional SetHTMLOptions; unsafe variants (streamBeforeHTMLUnsafe, streamAfterHTMLUnsafe, streamReplaceWithHTMLUnsafe) take optional SetHTMLUnsafeOptions or TrustedHTMLParserOptions.

Outputs. Return a new WritableStream whose underlying sink inserts parsed nodes into the node’s parent before the node (streamBeforeHTML*), after the node via its initial nextSibling anchor (streamAfterHTML*), or in place of the node after removing it immediately upon stream creation (streamReplaceWithHTML*). Unlike synchronous beforeHTML()/afterHTML()/replaceWithHTML(), calling a sibling streaming method on a detached node (null parent) throws HierarchyRequestError immediately.

Source: Blink non_document_type_child_node.idl; node.cc; html_stream.cc.

SetHTMLOptions, SetHTMLUnsafeOptions.runScripts, and setHTMLUnsafe()

Inputs. SetHTMLOptions configures safe insertion with sanitizer (Sanitizer, SanitizerConfig, or "default"; defaults to "default" and never permits script execution). SetHTMLUnsafeOptions configures unsafe insertion and streaming with optional sanitizer (no default sanitizer unless specified) and runScripts (boolean, default false). Passed to existing Element.setHTMLUnsafe() and ShadowRoot.setHTMLUnsafe() as well as every new *Unsafe positional and streaming method.

Outputs. When runScripts is false (default), inserted <script> elements are marked already-started and do not execute (matching innerHTML). When runScripts is true on synchronous *Unsafe methods, inserted scripts execute after insertion (matching Range.createContextualFragment() — external classic scripts do not block the synchronous call, without createContextualFragment’s pre-connection image preloading quirk). When runScripts is true on stream*Unsafe() methods, the streaming parser mirrors document parsing: classic scripts block further streamed parsing while executing, and defer / module scripts run when the stream closes.

Source: Blink element.idl; WICG explainer.

TrustedTypePolicy.createParserOptions(), TrustedHTMLParserOptions, and Document.parseHTMLUnsafe()

Inputs. Register a createParserOptions(input, ...args) callback in TrustedTypePolicyOptions when calling trustedTypes.createPolicy(name, options). Call policy.createParserOptions(options?, ...args) on the resulting TrustedTypePolicy (optional SetHTMLUnsafeOptions input, defaulting to {}, plus variadic arguments forwarded to the callback). The callback receives a cloned/validated SetHTMLUnsafeOptions object and returns the blessed options dictionary (modifying sanitizer or runScripts, or blessing as-is).

Outputs. Returns an opaque, non-fungible TrustedHTMLParserOptions object (exposing no mutable JS properties so callers cannot tamper with sanitizer or runScripts after policy approval). Passing that TrustedHTMLParserOptions instance to setHTMLUnsafe(), Document.parseHTMLUnsafe(html, options), or any *Unsafe positional or streaming method satisfies Trusted Types enforcement for parser options and enables streaming unsafe HTML under require-trusted-types-for 'script' without buffering through createHTML().

Source: Blink trusted_type_policy.idl; trusted_type_policy.cc; trusted_html_parser_options.idl; document.idl.

Errors and edge cases

Verified directly against Blink’s C++ guards in container_node.cc, node.cc, html_stream.cc, and trusted_type_policy.cc:

  • HierarchyRequestError — partial insertion on <html>: Calling appendHTML, appendHTMLUnsafe, prependHTML, prependHTMLUnsafe, streamAppendHTML, streamAppendHTMLUnsafe, streamPrependHTML, streamPrependHTMLUnsafe on document.documentElement (<html>) — or beforeHTML* / afterHTML* / replaceWithHTML* / streamBeforeHTML* / streamAfterHTML* / streamReplaceWithHTML* on a direct child of <html> — throws DOMException("HierarchyRequestError") before parsing or sanitizer validation. Use setHTML(), setHTMLUnsafe(), streamHTML(), or streamHTMLUnsafe() to replace <html>’s children instead.
  • HierarchyRequestError — invalid parent or detached streaming target: Calling beforeHTML* / afterHTML* / replaceWithHTML* (synchronous) on a detached node (parentNode === null) is a no-op, whereas calling streamBeforeHTML* / streamAfterHTML* / streamReplaceWithHTML* on a detached node throws HierarchyRequestError. Calling any sibling method on a direct child of <template>, or under a non-Element/non-ShadowRoot parent (such as Document or a non-template DocumentFragment), throws HierarchyRequestError.
  • NotSupportedError — streaming into <script>: Calling streamHTML*, streamAppendHTML*, or streamPrependHTML* on an HTMLScriptElement throws DOMException("NotSupportedError").
  • Stream write rejections (TypeError & HierarchyRequestError): Writing a JavaScript Symbol chunk to any WritableStream returned by stream*HTML* stops the parser and rejects with TypeError("Cannot stream symbols into HTML"). Non-string values (including raw Uint8Array chunks if you forget TextDecoderStream) are coerced via WebIDL DOMString conversion, so always pipe byte streams through new TextDecoderStream(). If the reference anchor node for streamPrependHTML*, streamBeforeHTML*, streamAfterHTML*, or streamReplaceWithHTML* is removed or moved out of the target before a subsequent write(), the write stops the parser and rejects with HierarchyRequestError.
  • Trusted Types & Sanitizer TypeError: Calling policy.createParserOptions() when the policy’s TrustedTypePolicyOptions omitted a createParserOptions callback throws TypeError. Passing an invalid SanitizerConfig in SetHTMLOptions / SetHTMLUnsafeOptions, or passing a plain string / unblessed SetHTMLUnsafeOptions to setHTMLUnsafe(), Document.parseHTMLUnsafe(), or any *Unsafe positional/streaming method when CSP require-trusted-types-for 'script' is enforced without a matching default policy, throws TypeError.
Source: Blink container_node.cc; node.cc; html_stream.cc; trusted_type_policy.cc.

Context and exposure

  • Window-only DOM exposure: Element, ShadowRoot, CharacterData, Document.parseHTMLUnsafe(), TrustedHTMLParserOptions, and TrustedTypePolicy.createParserOptions() are all [Exposed=Window]. (TrustedTypePolicy itself is exposed in both Window and Worker, but createParserOptions() is explicitly [Exposed=Window] in Blink’s trusted_type_policy.idl.)
  • No secure context or permission required: All insertion, streaming, and parser-options APIs work in standard HTTP/HTTPS browsing contexts with no permissions or user activation required.
  • Template element targeting: Calling container methods (appendHTML*, prependHTML*, streamHTML*, streamAppendHTML*, streamPrependHTML*) on an <HTMLTemplateElement> inserts into template.content rather than as light-DOM children of the <template> element itself.
Source: Blink trusted_type_policy.idl; container_node.cc.

Lifecycle, streaming state, and script execution order

  1. Synchronous positional calls: Validate Trusted Types (on *Unsafe), check parent/container validity (<html> guard precedes sanitizer validation), parse the HTML fragment with the resolved sanitizer, insert or replace nodes in a single DOM mutation (firing CEReactions custom-element callbacks), and finally execute any inserted <script> elements if runScripts: true.
  2. Streaming initialization: Creating a stream validates Trusted Types and parent/target eligibility synchronously. streamHTML* clears existing children immediately and streamReplaceWithHTML* removes the target node immediately upon stream creation (using its original nextSibling as the insertion anchor).
  3. Incremental chunk writes & backpressure: Each writer.write(chunk) (or pipeTo() chunk) feeds decoded text into the underlying HTMLDocumentParser, inserting parsed elements progressively into the live DOM and yielding to the event loop between network chunks.
  4. Completion (close()) and cancellation (abort()): Closing the WritableStream calls Parser().Finish(), closes any open tags per HTML parsing rules, runs defer/module scripts (when runScripts: true), and resolves the close promise once parsing completes. Calling abort() aborts the fragment parser (if a streamed parser-blocking script calls abort() while running, abort defers until the current chunk finishes).
Source: Blink html_stream.cc; container_node.cc; WICG explainer.

Examples

Positional HTML insertion on Element, ShadowRoot, and CharacterData

function updateListPositional(listEl, activeItem, shadowRoot, markerComment) {
  if (typeof listEl.appendHTML !== "function") return;

  // Container positional methods (safe by default with Sanitizer "default")
  listEl.appendHTML("<li>Appended item</li>");
  listEl.prependHTML("<li class=\"pinned\">Pinned item</li>");

  // Unsafe variants accept custom sanitizer or { runScripts: true }
  shadowRoot.appendHTMLUnsafe("<p>Shadow footer</p>", { runScripts: false });
  shadowRoot.prependHTMLUnsafe("<p>Shadow header</p>");

  // Sibling positional methods (NonDocumentTypeChildNode: Element & CharacterData)
  activeItem.beforeHTML("<li class=\"divider\">Before</li>");
  activeItem.afterHTML("<li class=\"divider\">After</li>");
  activeItem.replaceWithHTML("<li class=\"active\">Updated item</li>");

  // Works on Comment / Text nodes too (CharacterData)
  markerComment.beforeHTMLUnsafe("<span>Before comment</span>");
  markerComment.afterHTMLUnsafe("<span>After comment</span>");
  markerComment.replaceWithHTMLUnsafe("<span>Replaced comment</span>");
}
Source: Blink element.idl; non_document_type_child_node.idl.

Streaming HTML via WritableStream

Interactive demos exercising the element.streamAppendHTML() WritableStream and positional insertion methods are available on the sibling Chrome Platform Showcase v152 streaming HTML demo and positional methods demo (no dedicated /v157/ showcase route is published yet).

async function streamPartialResponse(container, placeholderNode, url) {
  if (typeof container.streamHTML !== "function") return;

  const response = await fetch(url);
  if (!response.ok || !response.body) return;

  // Always decode UTF-8 bytes to strings via TextDecoderStream before piping
  await response.body
    .pipeThrough(new TextDecoderStream())
    .pipeTo(container.streamHTML()); // clears container and streams sanitized children

  // Container append / prepend streaming (safe & unsafe)
  const appendWriter = container.streamAppendHTML().getWriter();
  await appendWriter.write("<article>Streamed tail</article>");
  await appendWriter.close();

  const prependStream = container.streamPrependHTMLUnsafe({ runScripts: false });
  await prependStream.getWriter().close();

  // Sibling streaming methods on Element or CharacterData
  const beforeStream = placeholderNode.streamBeforeHTML();
  const afterStream = placeholderNode.streamAfterHTML();
  await beforeStream.getWriter().close();
  await afterStream.getWriter().close();

  const replaceWriter = placeholderNode.streamReplaceWithHTML().getWriter();
  await replaceWriter.write("<section>Loaded replacement</section>");
  await replaceWriter.close();

  // Unsafe streaming variants (require Trusted Types if enforced)
  void container.streamHTMLUnsafe;
  void container.streamAppendHTMLUnsafe;
  void placeholderNode.streamBeforeHTMLUnsafe;
  void placeholderNode.streamAfterHTMLUnsafe;
  void placeholderNode.streamReplaceWithHTMLUnsafe;
}

runScripts and Trusted Types createParserOptions()

async function streamWithTrustedParserOptions(hostEl, htmlStream) {
  // 1. Direct unsafe call with SetHTMLUnsafeOptions { runScripts } (when Trusted Types not enforced)
  hostEl.setHTMLUnsafe("<div>Widget</div><script>/* runs after insert */</script>", {
    runScripts: true,
  });

  // 2. Trusted Types policy blessing parser options for streaming & parseHTMLUnsafe()
  if (window.trustedTypes && "createParserOptions" in TrustedTypePolicy.prototype) {
    const policy = window.trustedTypes.createPolicy("app-partial-html", {
      createParserOptions(input) {
        // Policy enforces a sanitizer and explicitly forbids arbitrary script execution
        return {
          sanitizer: input.sanitizer ?? { elements: ["div", "p", "span", "a", "strong"] },
          runScripts: false,
        };
      },
    });

    // Returns an opaque, non-fungible TrustedHTMLParserOptions instance
    const blessedOptions = policy.createParserOptions({ runScripts: true });

    // Accepted by stream*Unsafe(), *HTMLUnsafe(), setHTMLUnsafe(), and Document.parseHTMLUnsafe()
    hostEl.setHTMLUnsafe("<p><strong>Verified</strong></p>", blessedOptions);
    const parsedDoc = Document.parseHTMLUnsafe("<p>Parsed</p>", blessedOptions);
    void parsedDoc;

    await htmlStream
      .pipeThrough(new TextDecoderStream())
      .pipeTo(hostEl.streamAppendHTMLUnsafe(blessedOptions));
  }
}

Security and privacy

  • Safe-by-default naming split: Every non-*Unsafe method (appendHTML, prependHTML, beforeHTML, afterHTML, replaceWithHTML, and stream*HTML) enforces the Sanitizer API safe baseline, strips active/XSS-capable markup, and cannot enable runScripts. Only explicitly named *Unsafe methods accept unsanitized HTML or { runScripts: true }, making security-sensitive call sites auditable at a glance.
  • Trusted Types integration for streaming: Under CSP require-trusted-types-for 'script', every *Unsafe positional and streaming sink runs Trusted Types checks. Because TrustedHTMLParserOptions is opaque and non-fungible, a policy’s createParserOptions callback can enforce a sanitizer or override runScripts: false once up front, governing every streamed chunk without buffering the entire payload in JavaScript.
  • Memory safety & privacy: Streaming HTML parsing avoids accumulating large markup strings in heap memory on constrained devices and exposes no new persistent identifiers, cross-origin data, or fingerprinting surface beyond standard feature detection.
Source: WICG explainer (Security & Privacy Questionnaire); WICG Sanitizer API; w3c/trusted-types#594.
