Language Detector API on Android

The LanguageDetector Web API — on-device, offline-capable text-language detection — arrives on Chrome for Android in milestone 157. The API itself is not new: Chrome desktop has shipped it since 138 and Edge since 148. This milestone extends the existing, MDN-documented surface to Android; web applications can detect text languages locally on mobile devices without sending content to a server.

MDN: LanguageDetector API

MDN’s reference covers the interface in full — create(), availability(), detect(), download progress, quotas, examples, specifications, and browser compatibility (verified substantive, 2026-11-01).
