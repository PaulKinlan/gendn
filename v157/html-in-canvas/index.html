HTML-in-canvas

Lets web applications lay out live HTML descendants inside a <canvas content="drawable"> element and draw snapshots of elements marked with the drawable attribute into 2D Canvas (drawElementImage()), WebGL (texElementSubImage2D()), or WebGPU (GPUQueue.drawElementImageToTexture()) — while preserving DOM hit testing, accessibility geometry, worker-transferable ElementImage snapshots, and read-back-safe rendering.

Limited availability — shipped enabled by default in Chrome 157 and Edge 157; Firefox and Safari have not shipped

  • Edge · 157 (shipped 2026-11-05)

why it exists

Applications built on 2D Canvas, WebGL, and WebGPU — such as data visualizations, creative design tools, 3D scenes, and games — previously had to choose between re-implementing complex text layout, internationalization, form controls, and accessibility in JavaScript, or floating a detached DOM overlay above the canvas and manually synchronizing transforms and clipping. HTML-in-canvas unites both models: HTML descendants placed inside <canvas content="drawable"> participate in browser layout, keyboard focus, and the accessibility tree without painting directly to the page, while script draws their recorded snapshots into 2D, WebGL, or WebGPU pipelines and synchronizes hit-test geometry back to the DOM.

Compared to the earlier Chrome 148–150 origin trial documented at /v148/html-in-canvas/, the shipped Chrome 157 API replaces the boolean layoutsubtree attribute with content="drawable" plus per-subtree drawable attributes, changes drawElementImage() to return void and update geometry automatically by default, adds ElementImage for worker-thread OffscreenCanvas rendering, adds explicit geometry helpers (updateElementGeometry(), clearElementGeometry(), getElementTransform(), getElementImageDefaultSize(), requestPaint(), onelementgeometryupdate), renames WebGL’s upload method to texElementSubImage2D(), and standardizes WebGPU upload on GPUQueue.drawElementImageToTexture().

Source: WICG HTML-in-Canvas explainer; ChromeStatus API record 5172548013916160; blink-dev Intent to Ship.

Detailed member contracts follow below: content & drawable, onpaint / requestPaint() / CanvasPaintEvent, drawElementImage(), captureElementImage() / ElementImage / getElementImageDefaultSize(), updateElementGeometry() / clearElementGeometry() / getElementTransform(), onelementgeometryupdate / ElementGeometryUpdateEvent, texElementSubImage2D(), and GPUQueue.drawElementImageToTexture().

HTMLCanvasElement.content and the drawable attribute

Inputs. The content attribute on <canvas> accepts the enumerated keywords "fallback" (missing/invalid default) or "drawable", reflected as HTMLCanvasElement.content. Any descendant element you intend to draw must carry the boolean HTML content attribute drawable (for example, <form drawable> or el.setAttribute("drawable", "")).

Outputs & layout effects. Setting content="drawable" opts canvas descendants into normal layout (blockifying immediate children with static positioning) and exposes them to the accessibility tree while suppressing their direct page paint; descendants remain non-hit-testable until geometry is synced. Marking a descendant with drawable implies isolation: isolate and establishes a containing block for its descendants. Nested drawable elements form separate drawable subtrees: drawing an outer drawable element excludes nested drawable descendants and their subtrees so each can be composited independently.

Source: WICG HTML-in-Canvas explainer; Blink html_canvas_element.idl.

onpaint, requestPaint(), and CanvasPaintEvent

Inputs. Listen for paint via canvas.onpaint or canvas.addEventListener("paint", handler). Call canvas.requestPaint() (no arguments) to force a single paint event on the next rendering opportunity even when no drawable descendant invalidated. Programmatic construction accepts new CanvasPaintEvent(type, { changedElements }) where changedElements defaults to [].

Outputs. requestPaint() returns undefined and schedules a repaint check on the frame view. When dispatched, the CanvasPaintEvent exposes event.changedElements, a [SameObject] FrozenArray<Element> listing the canvas’s drawable descendants whose cached rendering snapshots changed since the last frame. Canvas draw calls executed inside the handler appear in the current frame; DOM mutations made inside the handler take effect on the subsequent rendering update.

Source: Blink canvas_paint_event.idl; Blink html_canvas_element.cc; WICG explainer.

CanvasDrawElementImage.drawElementImage() and DrawElementImageOptions

Inputs. Included on both CanvasRenderingContext2D and OffscreenCanvasRenderingContext2D. Accepts four overloads matching 2D drawImage() conventions: (element, dx, dy, options?), (element, dx, dy, dwidth, dheight, options?), (element, sx, sy, swidth, sheight, dx, dy, options?), and (element, sx, sy, swidth, sheight, dx, dy, dwidth, dheight, options?). element is an Element (main thread) or ElementImage (main thread or worker). Coordinates sx/sy/swidth/sheight are CSS-pixel offsets relative to the element’s border box before CSS transforms (and may extend outside the border box to capture ink overflow); dx/dy/dwidth/dheight are canvas coordinate-space coordinates. The optional DrawElementImageOptions dictionary accepts preserveElementGeometry (boolean, default false).

Outputs. Returns undefined (void). Draws the latest recorded snapshot of the element’s drawable subtree into the 2D context, scaling by default to preserve visual proportions relative to the canvas backing-grid scale factor when dwidth/dheight are omitted. When preserveElementGeometry is false (the default), Blink automatically invokes updateElementGeometry() with the active 2D transform mapping the element’s border box to its drawn destination and pushes the element to the top of the canvas hit-test stack. Passing { preserveElementGeometry: true } suppresses that automatic geometry update (for example, when drawing a shadow pass or duplicate reflection).

Source: Blink canvas_draw_element_image.idl; draw_element_image_options.idl; base_rendering_context_2d.cc.

captureElementImage(), ElementImage, and getElementImageDefaultSize()

Inputs. canvas.captureElementImage(element) takes an eligible drawable descendant Element on the main thread. canvas.getElementImageDefaultSize(element) and offscreenCanvas.getElementImageDefaultSize(element) accept either an Element or an ElementImage. elementImage.close() takes no arguments.

Outputs. captureElementImage() returns a transferable ElementImage object ([Exposed=(Window, Worker), Transferable]) holding an immutable handle to the element’s most recent cached paint record so it can be transferred to a worker via postMessage(img, [img]) and drawn onto an OffscreenCanvas (2D, WebGL, or WebGPU). Calling elementImage.close() releases the underlying paint record immediately (subsequent draw calls with a closed ElementImage throw InvalidStateError). getElementImageDefaultSize() returns an ElementImageDefaultSize dictionary { width, height } giving the element’s default raster size in canvas backing-grid coordinates (box_size * canvas_grid_scale_factor), useful for allocating WebGL/WebGPU textures or laying out draw calls.

Source: Blink element_image.idl; element_image_default_size.idl; html_canvas_element.cc; offscreen_canvas.idl.

updateElementGeometry(), clearElementGeometry(), and getElementTransform()

Inputs. Both HTMLCanvasElement and OffscreenCanvas expose updateElementGeometry(element, options?) and clearElementGeometry(element) accepting Element or ElementImage (worker threads must pass an ElementImage). UpdateElementGeometryOptions takes three optional fields: preserveHitTestOrder (boolean, default false — if true and the element is already in the canvas hit-test stack, keep its stack order; otherwise move it to the top), canvasClip (DOMRectInit evaluated in the coordinate space of canvasTransform; omitted preserves any existing clip), and canvasTransform (DOMMatrixInit mapping the element’s border box before CSS transforms into canvas coordinates; omitted preserves any existing transform). canvas.getElementTransform(element) takes a drawable Element on HTMLCanvasElement.

Outputs. updateElementGeometry() and clearElementGeometry() return undefined. Updating geometry sets the element’s hit-test transform, hit-test clip, hit-test stacking order, and accessibility bounding geometry without invalidating the element’s snapshot (so it does not trigger another paint event). clearElementGeometry() resets that geometry state so the element stops participating in hit testing and reverts to geometry-less accessibility reporting. getElementTransform(element) returns a new DOMMatrix reflecting the currently applied canvas transform, or an identity DOMMatrix if none is set.

Source: Blink update_element_geometry_options.idl; html_canvas_element.cc; WICG explainer.

onelementgeometryupdate and ElementGeometryUpdateEvent

Inputs. Attach a listener to the main-thread HTMLCanvasElement via canvas.onelementgeometryupdate or canvas.addEventListener("elementgeometryupdate", handler). Programmatic construction accepts new ElementGeometryUpdateEvent(type, { elements }) where elements defaults to [].

Outputs. Fires on the associated HTMLCanvasElement once batched geometry updates originating from a transferred OffscreenCanvas (via drawElementImage(), updateElementGeometry(), or clearElementGeometry()) have been applied on the main thread. event.elements is a [SameObject] FrozenArray<Element> listing the still-connected elements whose geometry changed in that batch; after this event fires, main-thread APIs such as getBoundingClientRect() and getElementTransform() reflect the worker’s updated transform.

Source: Blink element_geometry_update_event.idl; WICG explainer.

WebGL: texElementSubImage2D() and WebGLCopyElementImageConfig

Inputs. Exposed on WebGLRenderingContext and WebGL2RenderingContext (via WebGLRenderingContextBase): gl.texElementSubImage2D(target, level, xoffset, yoffset, element, config?). Pre-allocate texture storage first (for example via texImage2D with null data or texStorage2D). element is an Element or ElementImage. Optional WebGLCopyElementImageConfig accepts a source crop rectangle (sx, sy, swidth, sheight — all four must be specified together or all omitted) and a destination raster size (width, height — both must be specified together or both omitted).

Outputs. Returns undefined and uploads the element’s read-back-safe snapshot into the bound 2D texture at (xoffset, yoffset) for mip level level. Unlike 2D drawElementImage(), WebGL does not update DOM hit-testing geometry automatically because shader projections are opaque to the browser — call canvas.updateElementGeometry(element, { canvasTransform }) explicitly to align pointer events and accessibility bounds with your rendered 3D quad.

Source: Blink webgl_rendering_context_base.idl; webgl_copy_element_image_config.idl; webgl_rendering_context_base.cc.

WebGPU: GPUQueue.drawElementImageToTexture()

Inputs. device.queue.drawElementImageToTexture(source, destination) takes a GPUDrawElementImageSource dictionary (required source of type Element or ElementImage, plus optional sourceX, sourceY, sourceWidth, sourceHeight — must supply all four or none) and a GPUDrawElementImageDestination dictionary extending GPUImageCopyTextureTagged (required texture, plus optional mipLevel, origin, aspect, colorSpace, premultipliedAlpha, and optional size of type GPUExtent3D).

Outputs. Returns undefined and enqueues rasterization of the element’s cached snapshot into destination.texture on the GPU queue (the destination texture must include the required copy/render-attachment usages just like copyExternalImageToTexture()). As with WebGL, call updateElementGeometry() explicitly on the canvas or OffscreenCanvas whenever the rendered quad’s screen-space transform changes.

Source: Blink gpu_queue.idl; gpu_draw_element_image_source.idl; gpu_draw_element_image_destination.idl; gpu_queue.cc.

Errors and edge cases

Verified directly against Blink’s exception checks in html_canvas_element.cc, base_rendering_context_2d.cc, webgl_rendering_context_base.cc, and gpu_queue.cc:

  • InvalidStateError — missing content="drawable" or drawable attribute: Calling drawElementImage(), captureElementImage(), getElementImageDefaultSize(), getElementTransform(), texElementSubImage2D(), or drawElementImageToTexture() throws DOMException("InvalidStateError") if the enclosing <canvas> does not have content="drawable", if the passed Element lacks the drawable attribute, or if the element’s nearest ancestor <canvas> is not the target canvas.
  • InvalidStateError — no cached paint record or closed ElementImage: Calling drawElementImage(), captureElementImage(), getElementImageDefaultSize(), texElementSubImage2D(), or drawElementImageToTexture() before the first rendering update has recorded a snapshot (before the first onpaint / requestPaint() frame, or for a display: none element) throws InvalidStateError ("No cached paint record for element."). Passing an ElementImage after close() or after transferring it throws InvalidStateError ("The ElementImage has been closed.").
  • InvalidStateError — canvas mismatch in geometry helpers: Calling updateElementGeometry() or clearElementGeometry() with an Element or ElementImage belonging to a different <canvas> throws InvalidStateError. Passing an invalid canvasTransform matrix (for example, malformed DOMMatrixInit) propagates the DOMMatrix.fromMatrix() TypeError.
  • OperationError — partial crop/size options in WebGL and WebGPU: In texElementSubImage2D() (WebGLCopyElementImageConfig), specifying only a subset of (sx, sy, swidth, sheight) or only one of (width, height) throws DOMException("OperationError"). In GPUQueue.drawElementImageToTexture() (GPUDrawElementImageSource), specifying only a subset of (sourceX, sourceY, sourceWidth, sourceHeight) throws DOMException("OperationError").
  • Silent no-ops and onelementgeometryupdate omissions: In 2D drawElementImage(), non-finite or empty source/destination rects return without drawing (matching drawImage()). If a canvas descendant is disconnected before an asynchronous OffscreenCanvas batch commits, it is silently omitted from ElementGeometryUpdateEvent.elements; CanvasPaintEvent.changedElements only lists elements invalidated for the current update.
Source: Blink html_canvas_element.cc; base_rendering_context_2d.cc; webgl_rendering_context_base.cc; gpu_queue.cc.

Context and exposure

  • Main thread (Window): HTMLCanvasElement additions (content, onpaint, onelementgeometryupdate, requestPaint(), captureElementImage(), getElementTransform(), getElementImageDefaultSize(), updateElementGeometry(), clearElementGeometry()), CanvasPaintEvent, ElementGeometryUpdateEvent, CanvasRenderingContext2D.drawElementImage(), and WebGL texElementSubImage2D() are available in regular browsing contexts without requiring a secure context, permission prompt, or user activation.
  • Workers (Window and Worker): ElementImage (transferable), OffscreenCanvas geometry/sizing methods (getElementImageDefaultSize(), updateElementGeometry(), clearElementGeometry()), OffscreenCanvasRenderingContext2D.drawElementImage(), WebGL texElementSubImage2D(), and WebGPU GPUQueue.drawElementImageToTexture() work in workers using transferred ElementImage handles.
  • WebGPU secure context: GPUQueue (including drawElementImageToTexture()) inherits WebGPU’s [SecureContext] requirement (HTTPS or localhost) and adapter/device availability.
Source: Blink html_canvas_element.idl; element_image.idl; offscreen_canvas_rendering_context_2d.idl; gpu_queue.idl.

Lifecycle, ordering, and synchronization

  1. Snapshot recording during Update the Rendering: On each frame, after animation frames, style/layout, ResizeObserver, IntersectionObserver, and browser paint recording, Blink records read-back-safe snapshots of every drawable descendant of every <canvas content="drawable">.
  2. Reverse-order paint dispatch: For each canvas with at least one changed drawable subtree (or a pending requestPaint() call), Blink fires CanvasPaintEvent (paint) in reverse document order (child frames before parent documents) and reverse tree order within a document so nested canvases finish painting before ancestors snapshot them.
  3. Single-pass frame commit: Canvas draw calls executed inside onpaint commit in the current frame. Any DOM or CSS mutations made inside onpaint do not re-loop layout in the same frame; they produce updated snapshots on the next rendering update.
  4. Main-thread vs. OffscreenCanvas geometry batching: On the main thread, drawElementImage() (unless preserveElementGeometry: true), updateElementGeometry(), and clearElementGeometry() update hit-testing and accessibility geometry synchronously without re-triggering paint. On an OffscreenCanvas (main thread or worker), geometry updates are queued and flushed in a microtask (posted asynchronously to the main thread from a worker), applying atomically and firing a single elementgeometryupdate event on the backing HTMLCanvasElement.
  5. Resource cleanup: Calling elementImage.close() frees snapshot memory eagerly on either thread; transferring an ElementImage detaches the sender’s handle immediately.
Source: WICG HTML-in-Canvas explainer; Blink html_canvas_element.cc.

2D Canvas: interactive HTML form, default size, and geometry helpers

<canvas id="stage" content="drawable" style="width: 480px; height: 240px;">
  <form id="hud" drawable>
    <label for="player">Player name:</label>
    <input id="player" type="text" value="Ada">
    <button type="submit">Ready</button>
  </form>
</canvas>
function attachHtmlInCanvas2D(canvas, hud) {
  const ctx = canvas.getContext("2d");
  if (!ctx || !("drawElementImage" in ctx) || canvas.content !== "drawable") {
    return false;
  }

  let angle = 0;

  canvas.onpaint = (event) => {
    // event is a CanvasPaintEvent exposing event.changedElements
    const changed = event.changedElements;
    ctx.reset();

    // Query default raster dimensions in canvas backing-grid coordinates
    const { width, height } = canvas.getElementImageDefaultSize(hud);

    // Draw a subtle shadow copy without overwriting hit-test geometry
    ctx.save();
    ctx.globalAlpha = 0.25;
    ctx.drawElementImage(hud, 48, 48, width, height, { preserveElementGeometry: true });
    ctx.restore();

    // Draw the interactive copy; default preserveElementGeometry: false syncs hit-testing
    ctx.save();
    ctx.translate(40, 40);
    ctx.rotate(angle);
    ctx.drawElementImage(hud, 0, 0);
    ctx.restore();

    // Inspect the synced transform, or refine clip / clear geometry manually
    const currentMatrix = canvas.getElementTransform(hud);
    canvas.updateElementGeometry(hud, {
      preserveHitTestOrder: true,
      canvasTransform: currentMatrix,
      canvasClip: { x: 0, y: 0, width: hud.offsetWidth, height: hud.offsetHeight },
    });
    if (changed.length === 0 && hud.hidden) {
      canvas.clearElementGeometry(hud);
    }
  };

  // Keep canvas backing store aligned with device pixels and trigger a paint
  new ResizeObserver(([entry]) => {
    const box = entry.devicePixelContentBoxSize?.[0];
    if (box) {
      canvas.width = box.inlineSize;
      canvas.height = box.blockSize;
      canvas.requestPaint();
    }
  }).observe(canvas, { box: "device-pixel-content-box" });

  return {
    setAngle(nextAngle) {
      angle = nextAngle;
      canvas.requestPaint();
    },
  };
}

OffscreenCanvas in a Worker: captureElementImage(), ElementImage.close(), and onelementgeometryupdate

function attachOffscreenHtmlInCanvas(canvas, form, workerUrl) {
  if (!("captureElementImage" in canvas) || typeof canvas.transferControlToOffscreen !== "function") {
    return null;
  }

  const worker = new Worker(workerUrl);
  const offscreen = canvas.transferControlToOffscreen();
  worker.postMessage({ type: "init", canvas: offscreen }, [offscreen]);

  // Main thread captures an ElementImage snapshot on each paint and transfers it
  canvas.onpaint = () => {
    const snapshot = canvas.captureElementImage(form);
    worker.postMessage({ type: "frame", elementImage: snapshot }, [snapshot]);
  };

  // Fires on the main thread after worker OffscreenCanvas geometry updates apply
  canvas.onelementgeometryupdate = (event) => {
    for (const el of event.elements) {
      // el.getBoundingClientRect() and canvas.getElementTransform(el) now match worker draw
      void el.getBoundingClientRect();
    }
  };

  return worker;
}

// Worker-side handler (runs inside workerUrl):
function handleWorkerMessage(event, ctx) {
  if (event.data.type === "frame") {
    const img = event.data.elementImage;
    const size = ctx.canvas.getElementImageDefaultSize(img);
    ctx.reset();
    ctx.drawElementImage(img, 24, 24, size.width, size.height);
    img.close(); // Release snapshot resources immediately after drawing
  }
}

WebGL texElementSubImage2D() and WebGPU GPUQueue.drawElementImageToTexture()

function uploadElementToWebGL(canvas, gl, texture, cardEl, quadMatrix) {
  const { width, height } = canvas.getElementImageDefaultSize(cardEl);
  const texWidth = Math.max(1, Math.round(width));
  const texHeight = Math.max(1, Math.round(height));

  gl.bindTexture(gl.TEXTURE_2D, texture);
  gl.texImage2D(
    gl.TEXTURE_2D, 0, gl.RGBA, texWidth, texHeight, 0,
    gl.RGBA, gl.UNSIGNED_BYTE, null
  );
  // Optional WebGLCopyElementImageConfig: specify all 4 of (sx,sy,swidth,sheight) or none
  gl.texElementSubImage2D(gl.TEXTURE_2D, 0, 0, 0, cardEl, {
    width: texWidth,
    height: texHeight,
  });

  // WebGL requires explicit DOM hit-test / a11y synchronization
  canvas.updateElementGeometry(cardEl, { canvasTransform: quadMatrix });
}

function uploadElementToWebGPU(canvas, device, texture, panelEl, quadMatrix) {
  const { width, height } = canvas.getElementImageDefaultSize(panelEl);
  const w = Math.max(1, Math.round(width));
  const h = Math.max(1, Math.round(height));

  // GPUDrawElementImageSource + GPUDrawElementImageDestination
  device.queue.drawElementImageToTexture(
    { source: panelEl },
    { texture, size: { width: w, height: h, depthOrArrayLayers: 1 } }
  );

  canvas.updateElementGeometry(panelEl, { canvasTransform: quadMatrix });
}

Security and privacy

Because WebGL and WebGPU textures (as well as 2D getImageData()) permit pixel read-back, HTML-in-canvas enforces read-back-allowed rendering across both snapshot painting and paint-event invalidation (verified by Blink’s has_read_back_disallowed_content() check in base_rendering_context_2d.cc). Sensitive browser-private state is excluded from both the rendered snapshot and invalidation triggers:

  • Cross-origin content: Cross-origin embedded content (<iframe>, cross-origin <img>, cross-origin CSS <url> backgrounds/clip-paths, tainted <canvas>, and cross-origin SVG URI references) is not painted (same-origin iframes paint, excluding cross-origin content inside them).
  • User & OS secrets: :visited link styling, spellcheck/grammar markers, pending browser autofill values not exposed to JavaScript, system colors/themes not already observable via forced-colors, subpixel text anti-aliasing, native media captions/controls, and IME pop-ups/composition styling are excluded.
  • Accessibility hygiene: Unused or hidden drawable descendants still exist in the accessibility tree unless removed or marked aria-hidden="true" / inert; elements without updated geometry are exposed to assistive technologies without bounding boxes so ATs can filter them.
Source: WICG HTML-in-Canvas explainer (Read-back-allowed rendering & Accessibility); WICG Security & Privacy Questionnaire; Blink base_rendering_context_2d.cc.
