Global Privacy Control in Chrome

Starting in Chrome 157, eligible users get a Chrome privacy setting that sends an opt-out request to websites about the use of their data. With the setting enabled, Chrome appends the Sec-GPC: 1 HTTP header to outgoing requests and exposes navigator.globalPrivacyControl === true to scripts — the Global Privacy Control signal that Firefox has sent since version 120. The web-facing surfaces (header and API) are not new; what’s new is Chrome emitting them, as a user-controlled, off-by-default setting on a stepped rollout.
