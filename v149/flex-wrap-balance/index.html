flex-wrap:balance

A new value for flex-wrap — introduced in developer trial in Chrome 149 and enabled by default in Chrome 150 — that distributes flex items across lines so the lines have roughly equal content, bringing text-wrap:balance-style balancing to flex lines. Useful for tag clouds, pill groups, and card grids where the last line would otherwise be jarringly short.

Limited availability — Chromium-only (Chrome 150 / Edge 150 since June–July 2026); MDN now publishes full canonical documentation for flex-wrap: balance (checked 2026-11-27)

why it exists

When you have a flex container with flex-wrap: wrap and the items don’t divide evenly across lines, the last line ends up with fewer items than the others. For a tag cloud this looks visually uneven — all full lines above a single orphaned chip at the bottom. flex-wrap: balance runs a balancing algorithm that adjusts line breaks so the number of items per line is as equal as possible, producing a tidier grid-like appearance without switching to display: grid.

Source: chromestatus summary + CSS Flexbox Level 2.
