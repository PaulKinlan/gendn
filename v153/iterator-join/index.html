Iterator Join

Adds Iterator.prototype.join(separator), concatenating every value yielded by an iterator into a single string separated by commas or an explicit separator string — mirroring Array.prototype.join() without allocating an intermediate array.

Limited availability on webstatus.dev — shipped in Chrome 153, Edge 153, Firefox 154, and Safari 27.3 (per BCD)

what Chrome 153 actually does

Verified against ECMA-262 Iterator.prototype.join, the TC39 Iterator Join proposal draft, and ChromeStatus 5095183554314240:

  • Default separator & abrupt close: When separator is omitted or undefined, "," is used. Otherwise ToString(separator) runs before advancing the iterator; if coercion throws (for example, passing a Symbol or an object whose toString() throws), the engine invokes IteratorClose on this before rethrowing.
  • undefined and null stringify to empty strings: Just like Array.prototype.join(), yielded undefined and null elements contribute "" (preserving the surrounding separator), while all other values are converted via ToString(value) with IteratorClose called on any conversion error.
  • Single-pass consumption: Consumes the iterator lazily to completion in one pass without creating an intermediate array (calling join() on an infinite iterator will not terminate).
  • Feature detection & fallback: Check typeof Iterator !== "undefined" && typeof Iterator.prototype.join === "function"; fall back to Array.from(iter).join(separator) or an explicit loop on older runtimes.
function iteratorJoin(iter, separator = ",") {
  if (typeof iter.join === "function") {
    return iter.join(separator);
  }
  const sep = String(separator);
  let out = "";
  let first = true;
  for (const value of iter) {
    if (!first) out += sep;
    first = false;
    if (value !== undefined && value !== null) {
      out += String(value);
    }
  }
  return out;
}
