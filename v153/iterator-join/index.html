Iterator Join

Adds Iterator.prototype.join(separator) to JavaScript — the iterator analogue of Array.prototype.join(). It consumes the iterator and returns a single string that is the concatenation of every yielded element, separated by a comma by default or by the optional separator string. Elements are converted to strings; undefined and null become the empty string, and an empty iterator joins to "". Unlike most iterator helpers it is not lazy, so it must not be called on an infinite iterator. The TC39 proposal is at Stage 3 and Chrome 153 ships it enabled by default.

quick reference

The changeOne method on the iterator helpers prototype: Iterator.prototype.join(separator?) → string. Behaves like Array.prototype.join() over the values the iterator yields: default separator ",", elements stringified, undefined/null → "", empty iterator → "". Eager (consumes the whole iterator), so unsuitable for infinite iterators
