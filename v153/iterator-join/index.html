Iterator Join

Adds Iterator.prototype.join() to JavaScript — a means to concatenate the contents of an iterator into a string. It works like Array.prototype.join(): it returns a string that is the concatenation of all elements produced by the iterator, separated by commas or a specified separator string, except that it operates on its receiver as an iterator rather than as an Array — no intermediate array allocation. The TC39 Iterator Join proposal is at Stage 3 (“ready for implementations”).

The changeOne prototype method on Iterator: Iterator.prototype.join(separator?).
