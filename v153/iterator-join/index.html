Iterator Join

Adds Iterator.prototype.join(separator) — the iterator-helper counterpart of Array.prototype.join(). It consumes the receiver as an iterator and returns the string concatenation of every produced value, separated by separator (a single comma when separator is undefined). Values that are undefined or null contribute the empty string; everything else goes through ToString. A single-value iterator returns that value’s stringification with no separator at all. The TC39 proposal is at Stage 3 and V8 ships it by default from Chrome 153.

quick reference

The changeOne method on the iterator-helpers prototype: Iterator.prototype.join(separator). Per the spec algorithm: throws TypeError if this is not an Object; separator === undefined → ",", otherwise ToString(separator) is taken before the first next() call; each produced value is stringified with ToString except undefined/null, which contribute the empty string; an abrupt ToString of the separator or of a value closes the underlying iterator (IteratorClose), while errors thrown by the iterator itself do not trigger an extra close
