SVG Path Data API

Adds structured JavaScript access to SVG <path> geometry via three methods on SVGPathElement (SVGPathData mixin): getPathData() reads the base d attribute as an array of { type, values } segment objects (with optional { normalize: true } reducing commands to absolute M, L, C, and Z), setPathData() writes a segment array back to d, and getPathSegmentAtLength() returns the segment at a given distance along the path.

Limited availability — shipped in Firefox 137 and Chrome 160; Safari has not signaled implementation

  • Chrome · 160 (desktop, Android, WebView)
  • Edge · Mirrors Chromium (160)
  • Firefox · 137 (shipped April 2025)
  • Safari · No signal yet

what Chrome 160 actually does

In Blink’s svg_path_element.cc and svg_path_data.idl (verified against the svg/path/interfaces WPT suite):

  • Base d attribute only: All three methods read or mutate the element’s base d content attribute — CSS d: path(...) declarations, SMIL <animate attributeName="d">, and Web Animations do not alter getPathData() or getPathSegmentAtLength().
  • Valid-prefix truncation in setPathData(): Encountering an unknown command letter, wrong values.length (unlike the d string parser, extra parameters are not split into implicit repeats), non-finite numbers (NaN, Infinity), or non-empty values on Z/z stops parsing at that segment and retains only the valid preceding segments.
  • Attribute mutation & empty removal: Passing an empty array (or a list invalid at index 0) calls removeAttribute("d"); otherwise Blink serializes the valid-prefix byte stream through setAttribute("d", ...) so MutationObserver, <use> instances, and <mpath> dependencies update normally.
  • Distance clamping in getPathSegmentAtLength(distance): Returns null when the base path is empty; otherwise clamps distance to [0, getTotalLength()] so negative values return the first segment and values beyond total length return the last segment.
if ("getPathData" in SVGPathElement.prototype) {
  const path = document.querySelector("svg path");
  const normalized = path.getPathData({ normalize: true }); // M, L, C, Z only
  const atMidpoint = path.getPathSegmentAtLength(path.getTotalLength() / 2);

  // Translate every absolute M/L/C coordinate by +10px on X
  const shifted = normalized.map(({ type, values }) => ({
    type,
    values: values.map((v, i) => (i % 2 === 0 ? v + 10 : v)),
  }));
  path.setPathData(shifted);
  console.log({ segmentCount: shifted.length, atMidpoint });
}
