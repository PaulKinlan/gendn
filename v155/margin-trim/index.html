Margin-trim

The margin-trim CSS property lets a container discard the margins of its first and/or last child (block axis, inline axis, or both), so spacing inside a box is controlled by the container instead of leaking child margins into its padding. It generalizes the old quirks-mode margin collapsing hacks into one explicit, expressive property, and in Chrome 155 it is supported on regular block containers and multicol containers.
