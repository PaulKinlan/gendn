Margin-trim

The margin-trim CSS property may be used to omit margins before or after the first or last child of a container. Chrome 155 supports it on regular block containers and multicol containers. The effect resembles the quirks-mode margin quirk applied to p and heading elements inside body and table cells, but is more powerful, generic, and expressive. (A previous version of the spec also applied it to flex and grid containers; that was removed.)

quick reference

The changeChrome 155 ships the margin-trim property from CSS Box Model Level 4, on block and multicol containers: the container discards the block-start margin of its first in-flow child and/or the block-end margin of its last (e.g. margin-trim: block), per the css-box-4 draft
