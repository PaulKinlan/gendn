CSS4 text-decoration-skip-spaces

Limited availability

  • Chrome · 155 (desktop; Android not yet recorded)
  • Edge · not yet recorded
  • Firefox · not shipped, no signal
  • Safari · not shipped, no signal

Not a Baseline feature: webstatus.dev text-decoration-skip-spaces (queried 2026-10-18) records only Chrome 155 (2026-10-06) under browser_implementations and reports Baseline status limited. The ChromeStatus record lists Firefox and Safari views as “No signal”.

The text-decoration-skip-spaces CSS property controls whether text decoration lines — underlines, overlines, and line-throughs — are drawn over white space. It can skip spaces at the start and/or end of a line (start, end), skip all spaces and word separators (all), or decorate spaces like any other character (none). It applies to all decoration lines drawn by the element and any drawn by its ancestors, and ships enabled by default in Chrome 155 per the milestone=155 listing.

Source: CSS Text Decoration Level 4 (ED), § text-decoration-skip-spaces, fetched 2026-10-18; chromestatus.com/feature/4832783806627840
Chrome-only — and the trunk flag record still reads experimental

The milestone=155 listing files this under “Enabled by default”, and both BCD and webstatus.dev record Chrome 155 as shipped (desktop) — but as of 2026-10-18 the runtime flag record for CSSTextDecorationSkipSpaces still reads status: "experimental" at trunk, BCD records no Chrome-for-Android version, and no other engine has shipped or signalled. The draft also carries an open editor’s issue on the initial value (below). Feature-detect before relying on it: CSS.supports("text-decoration-skip-spaces", "none"). To test in an older or not-yet-flipped Chrome: chrome://flags/#enable-experimental-web-platform-features or --enable-blink-features=CSSTextDecorationSkipSpaces.

Values

The spec defines a spacer as “any typographic character unit in Unicode General Category Zs except U+202F NARROW NO-BREAK SPACE”. The property states whether and where decoration lines skip these, and the skipping also drops any adjacent letter-spacing or word-spacing:

none
Spacers are not skipped — they are decorated just like any other character.
all
Spacers and all word separators are skipped, along with any adjacent letter-spacing or word-spacing, wherever they occur in the line.
start
Spacers at the start of a line are skipped, along with any adjacent letter-spacing or word-spacing.
end
Spacers at the end of a line are skipped, along with any adjacent letter-spacing or word-spacing.

The property controls all decoration lines drawn by the element, and also any decoration lines drawn by its ancestors — so an outer underline (for example from a link wrapping a span) obeys the innermost element’s text-decoration-skip-spaces for the text it paints there, the same inheritance-of-painting model the rest of the text-decoration-skip-* family uses.

Source: value definitions and spacer definition quoted from CSS Text Decoration Level 4 (ED), fetched 2026-10-18

Examples

<p class="quoted">
  <a href="/где-то">  a link whose label has leading and trailing spaces  </a>
</p>

<style>
  /* Don't draw the underline under the leading/trailing spaces */
  .quoted a { text-decoration-skip-spaces: start end; }

  /* Decorate every character, spaces included (e.g. for <ins>/<del>
     diff views where the extent of the change must stay visible) */
  ins, del { text-decoration-skip-spaces: none; }

  /* Underline only the words, skipping every space and word separator */
  .words-only { text-decoration-skip-spaces: all; }
</style>

The use of none on ins/del mirrors the spec’s own suggestion that those elements may warrant none in the UA default stylesheet so edits to white space stay visible. No Chrome Platform Showcase demo exists for this feature yet (the showcase route /v155/css4-text-decoration-skip-spaces/ HEAD-checked 404 on 2026-10-18, so no iframe is embedded); the showcase v155 index lists what has been built. Security and privacy

The property is a paint-level typographic control with no scripting, network, or state surface. Its specification states, verbatim: “No new privacy considerations have been reported on this specification.” and “No new security considerations have been reported on this specification.”
