WebTransport receive stream

Adds the standardized WebTransportReceiveStream interface, a ReadableStream subclass used for incoming unidirectional streams and the readable side of bidirectional streams. Its getStats() method returns per-stream byte counters: bytesReceived reports bytes received from the network, while bytesRead reports bytes delivered to the application.

In developer trial in Chrome 155 — behind a flag

The milestone=155 listing files this under “In developer trial (Behind a flag)”, and the runtime flag record for WebTransportReceiveStream reads status: "experimental" at trunk (verified 2026-10-11); the ChromeStatus API record anticipates shipping in Chrome 158. To test in Chrome 155: enable chrome://flags/#enable-experimental-web-platform-features or launch with --enable-blink-features=WebTransportReceiveStream. The API surface may still move — don’t copy code into production. Firefox and Safari already ship the interface (see compatibility below), so feature-detect per browser, e.g. typeof WebTransportReceiveStream !== "undefined".
