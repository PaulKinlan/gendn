Import Text (Text Modules)

Text modules let JavaScript import the contents of a text file as a string, using the import-attributes syntax import text from "./file.txt" with { type: "text" } (static or dynamic). The module’s default export is the fetched resource decoded as UTF-8. It is a TC39 Stage 3 proposal championed by Eemeli Aro, integrated into HTML in April 2026, and ships enabled by default in Chrome 155.

this feature is documented on MDN

quick reference

// Static form (the proposal README's example, verbatim)
import text from "path/to/file.txt" with { type: "text" };

// Dynamic form
const { default: text } = await import("./file.txt", {
  with: { type: "text" },
});
Source: tc39/proposal-import-text README (static example verbatim); the dynamic form follows the standard import-attributes with option on import()
The changeA new import-attribute value: with { type: "text" } loads the referenced resource as a module whose default export is the source string (a Synthetic Module Record; the string is the resource decoded as UTF-8). No named exports; no encoding affordance (“No affordance for defining the encoding ought to be given” — the proposal README). Per the HTML integration PR, there is no MIME-type requirement and no well-formedness check on the string
