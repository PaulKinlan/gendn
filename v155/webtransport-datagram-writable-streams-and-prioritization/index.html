WebTransport Datagram writable streams and prioritization

Adds the modern WebTransport Datagram sending API. WebTransportDatagramDuplexStream.createWritable() creates independent WebTransportDatagramsWritable streams. Each writable has mutable sendGroup and sendOrder attributes for expressing relative priority among queued WebTransport data in the same send group; Chromium currently applies this ordering among Datagram writables. The implementation also reports the negotiated maximum outgoing Datagram payload size and discards oversized writes as the WebTransport specification requires.

In developer trial in Chrome 155 — behind a flag

The milestone=155 listing files this under “In developer trial (Behind a flag)”, and the runtime flag record for WebTransportDatagramsWritable reads status: "experimental" at trunk, depending on the WebTransportSendGroup flag (verified 2026-10-11); the ChromeStatus API record anticipates shipping in Chrome 159. To test in Chrome 155: enable chrome://flags/#enable-experimental-web-platform-features or launch with --enable-blink-features=WebTransportSendGroup,WebTransportDatagramsWritable. The API surface may still move — don’t copy code into production. Firefox 155 and Safari 26.4 already ship createWritable() (see compatibility below), so feature-detect, e.g. "createWritable" in transport.datagrams.
