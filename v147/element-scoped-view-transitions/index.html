Element-scoped view transitions

Limited availability

  • Chrome · 147
  • Edge · 147
  • Firefox · no support
  • Safari · no support

The view-transitions-element-scoped web-feature is Limited availability on webstatus.dev (implemented in Chrome, Chrome Android and Edge 147; no Baseline date; verified 2026-11-22). BCD api/Element.json records startViewTransition and activeViewTransition in Chrome 147 (Edge and Chrome Android mirror), Firefox and Safari false, and marks both experimental. Document-level view transitions are a separate, Baseline Newly available feature — that status does not extend to the element-scoped method.

Call element.startViewTransition() on any HTML element to run a view transition scoped to that subtree, rather than the entire document. Multiple element-scoped transitions can run concurrently, nested transitions work naturally, and position-fixed content outside the scope stays interactive throughout.

this feature is documented on MDN

MDN: Element.startViewTransition()

MDN's Element.startViewTransition() reference covers the element-scoped API — its syntax, the returned transition object and browser compatibility. gendn doesn't duplicate that here. Syntax

From the CSS View Transitions Level 2 editor’s draft, quoted verbatim (fetched 2026-11-22). The element method takes the same argument as the document method:

partial interface Element {
  ViewTransition startViewTransition(
    optional (ViewTransitionUpdateCallback or StartViewTransitionOptions) callbackOptions = {}
  );
  readonly attribute ViewTransition? activeViewTransition;
};

callback ViewTransitionUpdateCallback = Promise<any> ();

dictionary StartViewTransitionOptions {
  ViewTransitionUpdateCallback? update = null;
  sequence<DOMString>? types = null;
};

The returned ViewTransition gains a transitionRoot attribute (the element the transition is scoped to) in the same draft. MDN’s Element.startViewTransition() page documents parameters, return value and exceptions.

Source: css-view-transitions-2 §Element.startViewTransition(), §activeViewTransition and §transitionRoot (fetched 2026-11-22).

Examples

Live demo from the chrome-platform-showcase — Element-scoped view transitions (feature index, five concepts). The embed below is its FAQ Accordion concept: each item runs its own element-scoped transition, so opening two quickly animates both at once.

const panel = document.querySelector('#panel');

if ('startViewTransition' in Element.prototype) {
  // Only #panel's subtree takes part; the rest of the page stays interactive.
  const transition = panel.startViewTransition({
    update: () => updatePanel(panel),
    types: ['panel-swap'],
  });
  console.log(transition.transitionRoot === panel); // true
  await transition.finished;
} else {
  updatePanel(panel);
}
Source: IDL from css-view-transitions-2; feature detection per BCD api/Element.json (method absent outside Chromium 147+).
