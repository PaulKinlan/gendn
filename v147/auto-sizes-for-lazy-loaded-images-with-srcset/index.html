Auto Sizes for Lazy Loaded Images with Srcset

Setting sizes="auto" on a lazy-loaded <img> element with a srcset lets the browser compute the correct sizes value from the element's rendered layout width — eliminating manual media-query breakpoints in the sizes attribute and ensuring the right image is always selected.

this feature is documented on MDN

MDN: HTMLImageElement.sizes

MDN's HTMLImageElement.sizes reference covers the auto keyword, its interaction with loading="lazy" and srcset, browser compatibility, and the underlying HTML Living Standard. gendn doesn't duplicate that here.
