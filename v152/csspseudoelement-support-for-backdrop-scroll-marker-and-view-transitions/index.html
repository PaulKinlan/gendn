CSSPseudoElement support for ::backdrop, ::scroll-marker and ::view-transitions

Extends the CSSPseudoElement interface — returned by Element.pseudo(type) — to cover three additional pseudo-element types: ::backdrop, ::scroll-marker, and the view-transition pseudo-elements (::view-transition, ::view-transition-group(), etc.). Ships enabled by default in Chrome 152 (available behind a flag from Chrome 147).

Limited availability — Chromium-only (Chrome/Edge 152 for these pseudo-element types); no Firefox or Safari implementation yet (checked 2026-11-27)

  • Chrome · 152 (desktop, Android, WebView; base Element.pseudo() in 149)
  • Edge · 152 (mirrors Chromium)
  • Firefox · No signal (position #1345)
  • Safari · No signal (position #607)

The base css-object-model-csspseudoelement web-feature is Limited availability on webstatus.dev (Chrome/Edge 149), and BCD api/Element.json tracks ::backdrop, ::scroll-marker, and ::view-transition* values at Chrome/Edge 152 (Firefox and Safari false). Live MDN check on 2026-11-27: although MDN publishes base pages for Element.pseudo() and CSSPseudoElement, their prose still lists only ::after, ::before, and ::marker as valid types — omitting ::backdrop, ::scroll-marker, and ::view-transition* — so gendn retains this dedicated reference.

syntax

The CSSPseudoElement interface provides a JavaScript handle for pseudo-elements, obtained via Element.prototype.pseudo(type):

partial interface Element {
  CSSPseudoElement? pseudo(CSSOMString type);
};

The type parameter accepts a pseudo-element selector string. When type does not match a supported or rendered pseudo-element, the method returns null rather than throwing an exception (per CSS Pseudo-Elements Level 4 §7.2). Chrome 152 expands supported types to include ::backdrop, ::scroll-marker, and view-transition pseudo-elements:

Additional pseudo-element selector types supported by Element.prototype.pseudo() in Chrome 152
Pseudo-elementUse case
::backdropThe full-screen backdrop rendered behind <dialog> and fullscreen elements. Access it as dialog.pseudo('::backdrop') to read its computed style or attach event listeners.
::scroll-markerThe marker pseudo-elements generated by Scroll Snap / Scroll Marker Groups. Accessing these lets JavaScript collect metrics or programmatically interact with snap targets.
::view-transition*View-transition pseudo-elements (::view-transition, ::view-transition-group(), ::view-transition-image-pair(), ::view-transition-old(), ::view-transition-new()) created during a view transition. Accessing them enables geometry queries and style inspection during animation.
Source: CSS Pseudo-Elements Level 4 §7.2; CSS Pseudo-Elements Level 4 §7.1; ChromeStatus feature 6516055192240128.

example

// Works in Chrome 152+ (Chrome 147-151: required the experimental-web-platform-features flag)
const dialog = document.querySelector('dialog');
dialog.showModal();

// Access the ::backdrop pseudo-element
const backdrop = dialog.pseudo('::backdrop');
if (backdrop) {
  const style = backdrop.computedStyleMap();
  console.log('backdrop background:', style.get('background-color'));

  // Listen for clicks on the backdrop to close the dialog
  backdrop.addEventListener('click', () => dialog.close());
}
