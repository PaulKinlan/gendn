OpaqueRange

A new live range type for <textarea> and text <input> elements. Unlike DOM Range, an OpaqueRange operates over a form control’s value text rather than DOM nodes — enabling getBoundingClientRect(), the CSS Highlights API, and anchored popovers for inline suggestions, AI autocomplete, and spell-check UIs.

Limited availability — Chromium-only (Chrome 152+ / Edge 152+); positive standards signals from Mozilla and WebKit, no non-Chromium implementation yet

why it exists

Building inline-suggestion UI (AI autocomplete, spell-check, editor annotations) inside a <textarea> or <input> requires knowing the pixel position of a text offset in the control’s value — but there is no standard API for that. Today developers work around this by mirroring the control’s content into a hidden <div> overlay, measuring the clone, then positioning their UI relative to the clone. This is fragile and breaks whenever the control’s font, padding, or scroll position differs from the mirror. OpaqueRange makes the browser do the geometry: create a range over value text offsets, call getBoundingClientRect(), and get the correct on-screen bounds. The range is live — its offsets stay valid as the value is edited.

Source: blink-dev Intent to Experiment — OpaqueRange.

shape of the API

[Exposed=Window]
interface OpaqueRange : AbstractRange {
  DOMRect getBoundingClientRect();
  DOMRectList getClientRects();
  undefined disconnect();
};

partial interface HTMLTextAreaElement {
  OpaqueRange createValueRange(unsigned long start, unsigned long end);
};

The createValueRange(start, end) method creates a live range over characters in the control’s value. Offsets are 0-based character indices into the value string. If start > end, or if an offset exceeds the value length, the method throws an IndexSizeError DOMException. getBoundingClientRect() returns the union of client rects (or empty rect if not rendered or disconnected), getClientRects() returns line rects, and disconnect() stops tracking changes.

Source: whatwg/dom PR #1404; MSEdge OpaqueRange explainer.

Security and privacy: OpaqueRange operates strictly on the value text of form controls that script already has access to. It encapsulates internal control DOM by returning null for startContainer and endContainer, preventing script from inspecting internal Shadow DOM structure of native inputs or textareas.
