HTMLImageElement.replacedByUserAgent

Read-only boolean attribute reporting whether the <img> element is currently displaying substitute content provided by the user agent instead of its own image. It is the synchronous companion to the asynchronous uareplacestart/uareplaceend events — read it to catch a replacement that happened before your listeners were attached.

Origin trial — may change or be removed Part of the Chrome 152 origin-trial listing for the User Agent Image Replacement API. Enable locally with --enable-blink-features=UAImageReplacementAPI or register for the trial in the Origin Trials console; see the overview's enable steps.

syntax

// IDL, verbatim from Chromium html_image_element.idl (2026-08-23):
[RuntimeEnabled=UAImageReplacementAPI, Measure] readonly attribute boolean replacedByUserAgent;

// Usage:
const isReplaced = imageElement.replacedByUserAgent;   // boolean

The [Measure] extended attribute means Chromium records a use counter when the getter is accessed.

Source: html_image_element.idl

inputs

None — it is a read-only getter with no parameters and no setter. Assigning to it has no effect (silently ignored in non-strict mode; TypeError in strict mode, as for any read-only IDL attribute).

Source: html_image_element.idl (readonly attribute)

outputs

A boolean: true while the element's content is a user-agent-provided substitute, false otherwise. In the Chromium implementation the getter returns whether the element's layout disposition is currently image-replacement (replacedByUserAgent() { return HasImageReplacement(); } in html_image_element.cc) — it flips to true synchronously when replacement starts, before the corresponding asynchronous uareplacestart event fires.

Source: html_image_element.cc

errors

The getter never throws. When the UAImageReplacementAPI runtime feature is disabled the attribute does not exist at all — imageElement.replacedByUserAgent evaluates to undefined — so feature-detect with "replacedByUserAgent" in HTMLImageElement.prototype rather than reading the property blind.

Source: html_image_element.idl ([RuntimeEnabled=UAImageReplacementAPI])

context and exposure

Exposed on every HTMLImageElement in Window contexts when the UAImageReplacementAPI runtime feature is enabled (origin trial token or --enable-blink-features=UAImageReplacementAPI, per runtime_enabled_features.json5). The IDL declares no SecureContext restriction. Chrome-only: no other engine implements or has signalled support (ChromeStatus API record).

Source: runtime_enabled_features.json5; ChromeStatus API record

lifecycle

The value tracks the replacement lifecycle documented on the overview: false initially; true from the moment the user agent starts substituting (StartImageReplacement() sets the image-replacement layout disposition); back to false when the substitution finishes, fails, or is reverted and the element returns to its primary content. Replacement only starts on an image that has successfully loaded. The state is per-element and not persisted — a new document load starts at false.

Source: html_image_element.cc — StartImageReplacement / ResetImageReplacement; explainer

examples

// Late-attaching script: reconcile UI with a replacement that
// may already have happened (events are asynchronous).
const img = document.querySelector("img.product-view");

if ("replacedByUserAgent" in HTMLImageElement.prototype &&
    img.replacedByUserAgent) {
  // The visible pixels are UA-provided, not our product photo:
  document.querySelector(".dimensions-note").hidden = true;
}
Source: pattern from the explainer example (“Check if the replacement happened before this script executed”)

security and privacy

The attribute reveals only a boolean fact about the current element, and only after the user (or their configured policy) actually initiated a replacement — per the explainer's anti-fingerprinting section, pages must not be able to probe for replacement capability through it, and user agents may withhold replacement state entirely when it is sensitive. It never exposes the replacement content.
