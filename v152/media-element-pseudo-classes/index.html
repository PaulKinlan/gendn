Media element pseudo-classes

The :playing, :paused, :seeking, :buffering, :stalled, :muted, and :volume-locked CSS pseudo-classes match <audio> and <video> elements based on their state. This is one of the focus areas in Interop 2026.

this feature is documented on MDN

MDN: :playing CSS pseudo-class

MDN covers each pseudo-class with its own reference page — syntax, examples, specifications, and browser compatibility: :playing, :paused, :seeking, :buffering, :stalled, :muted, and :volume-locked. gendn doesn't duplicate that here.

Why gendn doesn't duplicate MDN: this site exists for Chrome features that have no MDN reference yet. When MDN covers a feature completely, the honest page is a pointer to the canonical reference plus the shipping metadata MDN doesn't track — duplicated prose would only drift out of sync.
