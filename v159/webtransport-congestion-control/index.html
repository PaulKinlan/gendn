WebTransport congestion control

Adds the congestionControl constructor option on WebTransportOptions and the matching read-only WebTransport.prototype.congestionControl attribute. Applications can hint "default", "throughput", or "low-latency" so the browser can select an appropriate QUIC congestion-control strategy for the session.

Newly available in Chrome 159 (with BCD option lag) — parent WebTransport is Baseline Newly available since 2026-03-24

  • Chrome · 159 (desktop, Android, WebView)

what Chrome 159 actually does

The W3C WebTransport specification defines congestionControl as a hint (and marks the option at risk because browsers are not required to ship distinct algorithms for every mode). In Chromium’s AdjustSendAlgorithm():

  • "default" keeps QUIC’s default send algorithm (CUBIC).
  • "throughput" switches the QUIC connection’s send algorithm to BBRv2 (quic::kBBRv2).
  • "low-latency" also currently selects BBRv2 (with a source comment referencing crbug 501268547 to revisit when a dedicated low-latency algorithm is available).
  • Global Finch override caveat: if Chromium’s disabled-by-default kWebTransportCongestionControl base feature is enabled with an algorithm parameter (CUBIC, Reno, BBRv1, or BBRv2), it overrides the per-connection hint in the network layer. As noted in WebTransport::congestionControl(), Blink currently returns the constructor option value directly rather than plumbing back a global-flag override.
// Feature-detect before relying on the hint or attribute.
const supportsCongestionControl =
  typeof WebTransport !== "undefined" &&
  "congestionControl" in WebTransport.prototype;

const wt = new WebTransport("https://example.com:4433/wt", {
  congestionControl: "low-latency", // "default" | "throughput" | "low-latency"
});
await wt.ready;

// Spec permits engines (such as Firefox) to fall back to "default".
console.log(supportsCongestionControl ? wt.congestionControl : "unsupported");
Source: Chromium dedicated_web_transport_http3_client.cc; Blink web_transport.cc; WPT congestion-control.https.any.js.
